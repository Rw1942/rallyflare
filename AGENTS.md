# Notes for coding agents

Rallyflare runs Email2ChatGPT: people email the service and get replies generated by OpenAI models, and an admin dashboard manages settings and message history. It is four Cloudflare Workers in an npm workspace (`services/ingest`, `services/ai`, `services/mailer`, `services/attachments`) that call each other through service bindings, with D1 migrations in `migrations/` and shared types in `shared/`.

## Cloudflare operations

Agents deploy and change infrastructure directly. Two tools cover it, and both authenticate with the `CLOUDFLARE_API_TOKEN` environment variable for account `3c526a82504f460f254335ac81d313dd`:

- **Wrangler** (`npx wrangler`, run from inside the service's directory, or from the root with `--config services/<service>/wrangler.toml`) for anything tied to `services/ingest/wrangler.toml` (Worker `rallyflare`, which the README calls rally-ingest, with D1 `rally-database`), `services/ai/wrangler.toml` (`rally-ai`), `services/mailer/wrangler.toml` (`rally-mailer`) and `services/attachments/wrangler.toml` (`rally-attachments`, with R2 bucket `rally-attachments`): deploys, versions and rollback, D1 migrations and queries, secrets, and `wrangler tail`. Only the ingest config binds the database, so run migrations from `services/ingest` with `npx wrangler d1 migrations apply rally-database --remote`. The root package.json scripts do not fit because the root has no Wrangler config; `.cursor/rules/deployments.mdc` has the deploy order and common D1 queries.
- **Cloudflare Code Mode MCP** (`cloudflare-api` in `.mcp.json`) for the rest of the account: DNS, routes and custom domains, zone and Worker settings, analytics, other Workers and their resources, and the Cloudflare docs. Call `search` to find the endpoint, then `execute` with `account_id` set to the account ID above. `docs` searches the developer docs. Results are cut off at about 6,000 tokens, so filter inside the code instead of returning whole lists.

Both act on production; none of the Wrangler configs defines a staging environment. `.claude/settings.json` allows these tools without prompts and still asks before a force push or deleting a Worker, database, bucket or namespace. Account-wide setup, token permissions and the inventory of every project are in the `Rw1942/cloudflare-account` repo, `docs/agent-setup.md`.
